# Gameplay website — multi-page starter

This version uses dedicated category pages instead of an on-page category filter.

## Main files
- `index.html` — homepage and six category links
- `articles.html` — all-articles listing
- `categories/` — six individual category landing pages
- `articles/article-template.html` — reusable article-page layout
- `quests.html`, `community.html`, `profile.html` — structural placeholder pages
- `style.css` — shared responsive styling
- `script.js` — retained starter interactions (not required for page navigation)

## Category pages
1. `categories/growing-greener-living.html`
2. `categories/energy-water-smarts.html`
3. `categories/waste-less.html`
4. `categories/smarter-spending.html`
5. `categories/food-everyday-eating.html`
6. `categories/mind-wellbeing.html`

## Preview
Open `index.html` in a browser. Keep the folder structure intact so relative links and stylesheets work.

## GitHub Pages
Upload the contents of this folder to the root of your repository, preserving the `categories` and `articles` folders. The homepage is `index.html`.

## Cloudflare Web Analytics
Analytics is not enabled yet. Create a site in Cloudflare Web Analytics and paste the exact official beacon snippet Cloudflare gives you into the `<head>` of `index.html`. Add it to other pages too if you want analytics to load consistently on every page. Do not invent or reuse a token.

## Content boundary
Article titles, summaries, and body text are intentionally represented by visual placeholders. Replace those placeholders with your own content when ready.

# Gameplay — responsive website starter

This is a static HTML/CSS/JavaScript starter inspired by the approved mobile mockup.

## Files
- `index.html` — page structure and placeholder blocks
- `style.css` — responsive design and colours
- `script.js` — demo navigation, search panel, and simple tab states

## Preview locally
Open `index.html` in a browser. For a more reliable local preview, use a simple static server or upload the files to GitHub Pages.

## Content
The article text and card descriptions are intentionally represented by placeholder bars. Replace them when you are ready. The example photos load from Unsplash and need an internet connection; you can swap their URLs for your own images later.

## Cloudflare Web Analytics
Analytics is not active until you create a Cloudflare Web Analytics site and add the official beacon snippet Cloudflare provides. In `index.html`, replace the comment in the `<head>` with that exact snippet. Do not guess or reuse a beacon token.
